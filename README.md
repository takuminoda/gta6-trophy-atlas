An offline guide and tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI. Official names, descriptions and grades, saved progress, kind filters, spoiler mode, a staged platinum roadmap, missable flags, and a cited guide for every trophy. Static files only — no build step, no network at runtime.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

To regenerate the graded dossier:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

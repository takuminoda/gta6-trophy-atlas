A no-nonsense offline field guide to all 55 GTA VI trophies: exact names, descriptions and grades, saved progress, kind filters, spoiler mode, a staged platinum roadmap, missable flags and a cited source for every entry. Pure static files, no build step, no network at runtime.

## Run it

Regenerate the graded dossier in the default output directory:

```sh
node main.ts
```

Or send it to a directory of your choice:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
